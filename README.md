# Boston Housing Price Prediction using Random Forest Regression

This project explores machine learning regression techniques for predicting housing prices using the Boston Housing dataset.

The project includes:
- Exploratory Data Analysis (EDA)
- Data Preprocessing
- Model Training
- Model Evaluation
- Data Visualization

---

## Project Objective

The objective of this project is to build a regression model capable of predicting continuous housing prices based on different housing features.

---

## Dataset

Dataset used:
- Boston Housing Dataset

Source:
- https://github.com/selva86/datasets

---

## Tasks Performed

### 1. Data Collection
- Loaded dataset from GitHub repository

### 2. Exploratory Data Analysis (EDA)
- Statistical summary
- Data inspection
- Correlation analysis
- Feature visualization

### 3. Data Preprocessing
- Feature selection
- Train-test split

### 4. Model Training
- Random Forest Regression model

### 5. Model Evaluation
Evaluation metrics used:
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score
